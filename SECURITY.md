# Security and Privacy Policy

## Supported versions

This repository is in the scaffold phase. Only the latest commit on `main` is in
scope; there is no production release or security-update promise yet.

## Reporting a vulnerability or privacy failure

Do not open a public issue for a vault weakness, key exposure, PII leak, authorization
bypass, insecure backup, deep-link vulnerability, or unsafe platform behavior. Email
`auroral.sunflower@gmail.com` with:

- the affected repository, platform, version, and commit;
- a concise impact statement;
- reproducible steps using synthetic data; and
- suggested containment or mitigations, if available.

You should receive an acknowledgement within five business days. Please allow time
for validation and a coordinated fix before disclosure. This project does not
currently operate a bug-bounty program.

Never include real patient information, live credentials, signing keys, access
grants, or data obtained from systems you are not authorized to test. If a credential
or signing artifact was exposed, rotate or revoke it immediately; deleting a Git
commit or application build is not sufficient.
