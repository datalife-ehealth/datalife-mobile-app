# Support

Use GitHub issues for reproducible defects, scoped feature proposals, accessibility
problems, and documentation improvements. Include synthetic examples and remove
secrets and device identifiers before posting. Security and privacy reports belong in
the private channel described by [SECURITY.md](SECURITY.md).

This project cannot provide medical advice, recover production identity data, or
respond to a clinical emergency. Contact a qualified healthcare professional, the
relevant service operator, or local emergency services for those needs.
